# NSE Prediction

Research-led Indian equity intelligence platform (NSE first, BSE later).

## Project status

Early research and architecture scaffold. The immediate target is a fixture-backed earnings calendar and stock-intelligence dashboard. Validated recommendations, paper trading and eventual broker automation are separate gated milestones. No live trading is enabled.
